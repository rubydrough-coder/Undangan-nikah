# Undangan Azzah & Bayu

Undangan nikah interaktif 3D bergaya game. Satu file `index.html`, tanpa build.

## Pasang di GitHub Pages
1. Buka repo, klik `index.html`, ikon pensil (Edit), hapus isi lama, tempel isi baru, Commit changes.
   (Atau: Add file > Upload files, unggah `index.html` baru, ganti yang lama.)
2. Settings > Pages > Deploy from a branch > main / root > Save.

## Foto pengantin
Unggah dua foto potret (rasio 3:4) ke folder paling luar repo dengan nama:
- `foto-azzah.jpg`
- `foto-bayu.jpg`

## Ganti isi
Edit `index.html`: nama, tanggal, jadwal, teks surat, dan link Maps.
